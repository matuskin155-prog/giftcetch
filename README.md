# giftcatch — ловец подарков Telegram с чёрным фоном и красивым номером

## Что важно знать заранее

Когда вы улучшаете подарок, **фон, модель и узор выбирает сервер Telegram случайно**.
Ни бот, ни скрипт, ни «быстрое нажатие» на это не влияют. Повлиять можно только
на то, какие подарки вы улучшаете и сколько раз пытаетесь. Номер вы тоже не выбираете.

Поэтому бот делает две вещи:

1. **Ловит на вторичном рынке** (`snipe`). Следит за перепродажей в Telegram, находит
   подарки с чёрным фоном и красивым номером, присылает их вам в «Избранное» и, если
   вы разрешили, сам покупает в пределах лимита. Это единственный надёжный способ
   получить именно чёрный фон и именно красивый номер.
2. **Помогает с улучшением** (`chances`, `mine`, `upgrade`). Показывает шанс чёрного
   фона в коллекции, сколько улучшений в среднем на это уйдёт и сколько стоит такой же
   подарок на вторичке. Улучшает ваш подарок и сразу говорит, повезло или нет.

Бот работает от вашего аккаунта (это userbot через MTProto, библиотека Telethon).
Обычный бот из @BotFather покупать на вторичке не может.

## Установка

Нужен Python 3.11 или новее.

```bash
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp config.example.toml config.toml
```

1. Откройте https://my.telegram.org → **API development tools**, создайте приложение
   и впишите `api_id` и `api_hash` в `config.toml`.
2. Войдите в аккаунт: `python -m giftcatch login` (спросит телефон и код из Telegram).
   Появится файл `giftcatch.session`. **Никому его не передавайте**: с ним можно войти
   в ваш аккаунт.

## Команды

```bash
python -m giftcatch catalog                 # коллекции и сколько их на вторичке
python -m giftcatch chances "Plush Pepe"    # шанс чёрного фона и самый дешёвый такой на рынке
python -m giftcatch snipe                   # следить за рынком и ловить
python -m giftcatch mine                    # мои подарки, которые можно улучшить
python -m giftcatch upgrade 12345           # улучшить подарок (msg_id из mine)
```

## Настройка (`config.toml`)

**Что ловить**, раздел `[search]`:

- `gifts = ["*"]` — какие коллекции смотреть. Можно перечислить:
  `["Plush Pepe", "Durov's Cap"]`. Чем их меньше, тем быстрее круг.
- `backdrops = ["*Black*"]` — маска поймает и `Black`, и `Onyx Black`.
- `match` — что обязательно:
  - `both` — и фон, и номер (по умолчанию);
  - `backdrop` — только фон;
  - `number` — только номер;
  - `any` — что-то одно.

**Какие номера считать красивыми**, раздел `[numbers]`:

| Правило | Примеры |
|---|---|
| `max_number = 100` | 1–100 |
| `repdigits` | 77, 777, 8888 |
| `round` | 100, 2000, 50000 |
| `sequences` | 123, 1234, 4321 |
| `palindromes` | 1221, 12321 |
| `repeats` | 1212, 123123 |
| `extra = [...]` | ваши номера |

**Покупка**, раздел `[buy]`. По умолчанию `auto_buy = false`: бот только присылает
находки в «Избранное». Чтобы покупал сам, задайте:

```toml
auto_buy = true
max_price = 3000   # не дороже 3000 ⭐ за подарок
budget = 6000      # не больше 6000 ⭐ за запуск
max_count = 1      # купить один и остановиться
```

Перед оплатой бот запрашивает счёт у Telegram и сверяет итоговую сумму с лимитами.
Если продавец успел поднять цену, покупки не будет. Звёзды нужно заранее пополнить
на аккаунте.

## Ограничения

- Красивые номера с чёрным фоном встречаются редко, и их ловят другие снайперы.
  Режим `both` может молчать часами — это нормально.
- Слишком частые запросы приводят к флуд-ограничениям Telegram. Бот сам ждёт,
  сколько попросит Telegram, но не уменьшайте `request_delay` сильно.
- Лоты, которые продаются только за TON, бот покажет, но купить их звёздами не сможет.
- Автоматизация аккаунта — на ваш риск: соблюдайте
  [условия Telegram API](https://core.telegram.org/api/terms).
